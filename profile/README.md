<h2>一、英国家庭宽带的基本情况</h2>
<p>英国固网以光纤到户和部分铜缆混合为主，几家大运营商覆盖全国，另有大量区域性全光纤运营商在新建小区铺网。</p>
<p>家庭宽带的地址通常由运营商动态或静态分配给住户。静态住宅资源就是把这部分地址做成可长期租用的形式。</p>
<p>因为来源是家庭宽带，这类地址的 ASN 属于运营商宽带业务，而不是数据中心。这一点是它和机房 IP 的本质区别。</p>
<h2>二、怎么判断是不是原生</h2>
<p>看 ASN 归属、组织名、地址类型三项。ASN 是英国本地运营商，组织名对应宽带业务，类型标为 ISP 或住宅，基本成立。</p>
<p>再看地址的历史。是否出现在公开黑名单、是否被大量滥用过，这两项决定接入后的初始状态。</p>
<p>最后看稳定性。连续观察几天，地址是否变化、延迟是否规律。原生资源应该稳定，频繁跳变说明上游在调度。</p>
<h3>注册信息能说明什么</h3>
<p>whois 里的组织名和地址段用途，是判断归属最直接的证据。但注册信息可以转租，所以要配合实测一起看。</p>

<h2>六、续费和到期</h2>
<p>到期前确认续费价格。首月优惠、续费原价是常见做法，长期用要把续费价算进预算。</p>

<h2>常见问答</h2>
<h3>英国原生住宅 IP 和 ISP IP 是一回事吗？</h3>
<p>答：多数场景下指同一类资源，都是运营商宽带地址。叫法不同，关键看 ASN 归属和地址用途标记是否对得上。</p>
<h3>购买英国住宅 IP 需要英国身份吗？</h3>
<p>答：个人购买一般不需要。以公司名义采购可能涉及资质核验，具体看供应商要求，签合同前问清所需材料。</p>
<h3>英国家庭 IP 的延迟能优化吗？</h3>
<p>答：物理距离决定了下限，能优化的只有路由质量。选择绕路少、丢包低的线路，比追求标称延迟更有意义。</p>
<h3>可以只买一个月吗？</h3>
<p>答：多数供应商支持月付，部分有最短合同时长。短期验证选月付，长期使用可以谈季付或年付换折扣。</p>
